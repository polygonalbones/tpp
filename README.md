## tpp
tpp is a tiny compiler designed to compile C++ correctly, as fast as possible. It is inspired by projects like [tcc](https://bellard.org/tcc), [aburi](https://www.github.com/serjective/aburi), etc.

## Goals and Non-Goals
tpp **is** a compiler written for fun.

tpp **is** is aiming for C++17 as a baseline.

tpp **is not** a production-grade optimizing compiler, and by extension, a GCC/Clang replacement.

tpp **is not** guaranteed to work on all systems. The only systems I test on my x86_64 NixOS machine and a macOS Sonoma 14.8.9 Hackintosh.
